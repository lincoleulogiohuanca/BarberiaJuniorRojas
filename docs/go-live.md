# Checklist go-live

También puedes abrir un issue con plantilla **Go-live checklist**.

## Código

- [ ] Tema y Core en el servidor (ZIP o FTP deploy)
- [ ] Plugin Core activo + backfill si aplica
- [ ] Permalinks guardados de nuevo

## Pagos

- [ ] Culqi **live**
- [ ] Webhook configurado
- [ ] Medios Plin / estudio listos
- [ ] Una prueba de cobro controlada

## Operación

- [ ] HTTPS
- [ ] SMTP con correo de prueba OK
- [ ] Cron real
- [ ] Backup de base de datos del hosting

## QA

- [ ] Reservar / reprogramar / cancelar estudio
- [ ] Culqi sin doble cargo
- [ ] Comprobante manual
- [ ] Lista de espera / reseñas básicas
